# Smart Color Sorting

ระบบตรวจสอบสีวัตถุด้วย ESP32 + TCS3200 เทียบกับค่ามาตรฐานที่ตั้งไว้ พร้อมชดเชยผลกระทบจากอุณหภูมิ/ความชื้น (DHT11) และแสดงผลผ่าน OLED + LED

## อุปกรณ์ที่ใช้

| อุปกรณ์ | บทบาท |
|---|---|
| ESP32 | หน่วยประมวลผลหลัก |
| TCS3200 | ตรวจจับสีวัตถุ (RGB Color Sensor) |
| DHT11 | วัดอุณหภูมิ/ความชื้นของสภาพแวดล้อม |
| SSD1306 OLED | แสดงผลลัพธ์ |
| LED เขียว/เหลือง/แดง | แสดงสถานะ ผ่าน/กำลังประมวลผล/ไม่ผ่าน |
| RGB LED | แสดงสีที่วัดได้จริง |
| ปุ่มกด x2 | Set Standard / Check Color (กดสั้น) และ Calibrate (กดค้าง 2 วิ) |

## ตารางกำหนดขา (Pin Mapping)

| อุปกรณ์ | ขาอุปกรณ์ | ESP32 GPIO | หมายเหตุ |
|---|---|---|---|
| **TCS3200** | S0 | GPIO 32 | Output |
| | S1 | GPIO 33 | Output |
| | S2 | GPIO 25 | Output |
| | S3 | GPIO 26 | Output |
| | OUT | GPIO 34 | Input only |
| | LED | GPIO 2 | Optional — ⚠️ Strapping pin |
| **DHT11** | DATA | GPIO 4 | Digital I/O |
| **SSD1306 (I2C)** | SDA | GPIO 21 | I2C มาตรฐาน |
| | SCL | GPIO 22 | I2C มาตรฐาน |
| **ปุ่ม 1** (Set standard / Calibrate white) | — | GPIO 18 | `INPUT_PULLUP` |
| **ปุ่ม 2** (Check color / Calibrate black) | — | GPIO 19 | `INPUT_PULLUP` |
| **LED เขียว** (ผ่าน) | — | GPIO 13 | ผ่าน R 330Ω |
| **LED เหลือง** (ประมวลผล) | — | GPIO 14 | ผ่าน R 330Ω |
| **LED แดง** (ไม่ผ่าน) | — | GPIO 27 | ผ่าน R 330Ω |
| **RGB LED** | R | GPIO 5 | ผ่าน R 1kΩ |
| | G | GPIO 23 | ผ่าน R 1kΩ |
| | B | GPIO 15 | ⚠️ Strapping pin — ผ่าน R 1kΩ |
รวมทั้งหมด 15 ขา GPIO — ยังเหลือขาว่างอีกเยอะบน ESP32 (มี GPIO ใช้งานได้ ~25-30 ขา) ไม่ชนกันเลย

> ⚠️ **GPIO 2** และ **GPIO 15** เป็น strapping pin มีผลต่อการเข้า Boot/Download Mode ตอนอัปโหลดโค้ด หากเจอปัญหา `Wrong boot mode` ให้ลองถอดสายที่ต่อขาเหล่านี้ออกชั่วคราวระหว่างอัปโหลด

## กระบวนการทำงานโดยรวม

ระบบแบ่งการทำงานเป็น 3 ส่วนหลักที่ทำงานคู่ขนานกันแบบ non-blocking (ไม่มีจุดใดค้างรอจนระบบอื่นหยุดทำงาน):

### 1. การตั้งค่าเริ่มต้น (Calibration)

ก่อนใช้งานจริง ต้อง calibrate เซนเซอร์ TCS3200 ด้วยวัตถุอ้างอิง 2 ชิ้น (แผ่นขาว และวัตถุดำ) เพื่อให้ระบบรู้ขอบเขตค่าความถี่สูงสุด-ต่ำสุดของเซนเซอร์ ก่อนนำไปแปลงเป็นค่า RGB มาตรฐาน 0-255

- กดปุ่ม 1 ค้างไว้ 2 วินาทีขณะวางแผ่นขาวหน้าเซนเซอร์ → บันทึกค่าความถี่ต่ำสุด (white reference)
- กดปุ่ม 2 ค้างไว้ 2 วินาทีขณะวางวัตถุดำหน้าเซนเซอร์ → บันทึกค่าความถี่สูงสุด (black reference)
- เมื่อ calibrate ครบทั้งคู่ จอ OLED จะแสดง "Calibrated! Ready to use"

### 2. การตั้งค่ามาตรฐาน (Set Standard)

กดปุ่ม 1 แบบสั้น (ปล่อยเร็ว) เพื่อวัดสีวัตถุอ้างอิงเป็นเวลา 5 วินาที ระบบจะ:
- อ่านค่าความถี่จาก TCS3200 ต่อเนื่องหลายตัวอย่างแล้วหาค่าเฉลี่ย
- แปลงค่าความถี่ดิบ → RGB (0-255) โดยใช้ค่า calibration
- แปลง RGB → CIE XYZ → CIE L\*a\*b\* ตามสูตรมาตรฐานสากล (D65 illuminant)
- บันทึกค่า L\*a\*b\* นี้ไว้เป็น "ค่ามาตรฐาน" สำหรับเปรียบเทียบในการตรวจสอบครั้งถัดไป

### 3. การตรวจสอบสี (Check Color)

กดปุ่ม 2 แบบสั้นเพื่อวัดสีวัตถุที่ต้องการตรวจ เป็นเวลา 5 วินาทีเช่นกัน จากนั้นระบบจะ:
- แปลงค่าที่วัดได้เป็น L\*a\*b\* เหมือนขั้นตอน Set Standard
- คำนวณค่า **Delta E (CIE76)** ซึ่งเป็นระยะห่างทางคณิตศาสตร์ระหว่างสีที่วัดได้กับค่ามาตรฐาน:

  ```
  ΔE = √[(L2-L1)² + (a2-a1)² + (b2-b1)²]
  ```

- เทียบค่า ΔE กับเกณฑ์ที่ตั้งไว้ (ค่าเริ่มต้น 5.0) — ถ้า ΔE ≤ เกณฑ์ = **PASS**, มากกว่า = **FAIL**

### ระบบย่อยที่ทำงานคู่ขนานตลอดเวลา

- **DHT11** อ่านค่าทุก 2 วินาที เพื่อเช็คว่าอุณหภูมิอยู่ในช่วง 20-25°C และความชื้นอยู่ในช่วง 50-60% หรือไม่ ถ้าเกินช่วงจะแจ้งเตือนผ่าน Serial แต่ **ไม่หยุดการทำงานของระบบ**
- **LED เหลือง** กระพริบตลอดช่วงที่กำลังวัดค่า (5 วินาที) เพื่อบอกว่าระบบกำลังประมวลผลอยู่
- **LED เขียว/แดง** ติดค้างหลังวัดเสร็จ เพื่อบอกผล ผ่าน/ไม่ผ่าน
- **RGB LED** แสดงสีจริงที่วัดได้ตลอดเวลาหลังวัดเสร็จ (ใช้ PWM ผสมสี)
