# smart-color-sorter-esp32
TCS3200-based automated QC &amp; environmental monitoring system for CPE 213/214 Microprocessor project. Uses sensor arrays to detect object color accuracy and monitor ambient conditions (temp, humidity, light) in real time to ensure optimal inspection environments and streamline quality control workflows.
